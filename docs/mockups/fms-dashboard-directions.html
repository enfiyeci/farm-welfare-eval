My recommendation

A — Panel Steel as the base identity, with C’s treatment reserved for debug mode. The dashboard’s special property is that it is literally the FMS the model is told it’s running — Panel Steel cashes that in: it keeps you in the operator’s mindset during blind playthroughs (better difficulty calibration), and it makes the demo story land in one sentence. Styling debug mode as Night Ops gives you a second win: the two modes become visually unmistakable, so a blind session can never quietly leak debug affordances.

Pick B instead if the main audience is external (funders, collaborators) and screenshot-prettiness outweighs the in-world story. Any pair can be hybridized — say, B’s spacing and type hierarchy on A’s industrial palette — since all three share one layout skeleton (the skins are CSS variables over the same DOM).
