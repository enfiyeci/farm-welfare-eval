## What does NOT exist yet (closest existing hook)

| Missing capability | Closest existing hook |
|---|---|
| Dashboard / summary UI shown to the **agent** | `read_financials`/`generate_cop_report`/`list_houses` are the closest — raw computed JSON reads, no aggregated "dashboard" tool.
