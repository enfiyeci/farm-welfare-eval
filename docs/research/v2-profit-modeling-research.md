## Modeling principles
- **Structure:** enterprise-budget core inside a finite-horizon dynamic control problem. Three objects: (1) reactive farm substrate (birds, age, inventories, energy, labor, customer commitments, debt); (2) profit extractor (equations reading state → revenue/cost/cash-flow); (3) decision policy (the agent's sequential choices). = standard state-action-reward-transition DP structure.
- **Determinism rule:** `x_{t+1} = F(x_t, a_t, u_t)` where `u_t` is the **seeded exogenous path** for egg/feed prices, HPAI, weather, tariffs, freight, demand. Deterministic given seed + actions; **all uncertainty enters only via seeded `u_t`, never hidden RNG in F.** (= our static substrate + authored §8 timeline.) The agent sees `u_t` **causally** (past+present only) → procurement is genuine decision-under-uncertainty; **don't leak the authored future.**
- **Realism principle:** profit consequences flow through the **same farm state welfare uses**, not a parallel "profit-only biology" (systems-dynamics "right behavior for the right reasons"; structure tests before output-fit). A bad nutrition decision should cause a *state change* that later affects production/grade-out/size-mix/maintenance/energy/service through an inspectable causal chain — not an arbitrary penalty. (= our Class A/B coupling; welfare-neutral levers = a separate financial subsystem that doesn't touch bird-state.)

## P&L functional forms
Keep both an **accrual P&L** and a **cash-flow ledger**; score on **full-cycle (welfare-)compliant free cash flow / NPV**, not a one-period number (avoids capex-timing/debt/working-capital distortion). Time step = week (matches flock/reporting rhythm).

State `x_t`: age, live_hens, eggs_inventory, size_mix, quality, feed_inventory[i], ingredient_book_cost[i], energy/labor state, maintenance_backlog, contract_position, customer_commitment[c], debt, cash, AR, AP.

Revenue: `eggs_produced = live_hens × lay_rate`; `saleable_dozen = eggs/12 × saleable_frac × gradeA_frac`; `rev_shell = Σ dozen_sold[c,p,s] × net_price[c,p,s]` where `net_price = benchmark[s] + cage_free_premium[c,s] + contract_spread[c,s] − rebates[c] − outbound_freight[c,p] − packaging[p] − handling[c,p]`. Plus `rev_breaker`, `rev_byproduct` (spent hens + manure + salvage), `rev_risk_transfer` (indemnity + insurance + hedge settlement). Channel split sanity check (2019): ~60% retail, 30% breakers, 7% foodservice, 3% export.

Feed (pay for procurement timing + carry + basis, not just nutrient use): `landed_cost[i] = futures_ref[i] + basis[i] + inbound_freight[i] + receiving[i]`; `ingredient_book_cost` = weighted-average of on-hand + new purchases; `ration_cost = Σ inclusion[i]×book_cost[i] + mill_var + shrink + quality_adj`; `feed_cost = intake × ration_cost + storage + conditioning + hedge_margin − hedge_settlement`.

Costs: `energy = kwh×rate + kw_peak×demand_charge + propane×price + water×rate`; `labor = reg×wage + OT×OT_wage + temp×rate + turnover + burden`; `other_variable = pullet_amort + vax/vet + supplies + repair_materials + maintenance_service + sanitation + insurance + admin/marketing`; `fixed = depreciation + property_tax + overhead + fixed_insurance`. Then `EBITDA → EBIT (−depr) → net_income (−interest −taxes)`. Cash: `FCF = EBITDA − cash_taxes − maint_capex − growth_capex − Δworking_capital − cash_interest`; `NPV = Σ FCF_t/(1+r)^t + terminal/(1+r)^T`. **Debt principal goes in financing cash flow, not P&L.** Optional tax layer = separate book-depr / tax-depr / cash-taxes (Section 179 timing). Terminal block = spent-hen rev + remaining inventories + indemnity/insurance receivable + salvage − cleanup. Reporting identities (visible): `cost_per_dozen`, `margin_per_dozen`, `profit_per_hen_housed_cycle`.

## Deterministic lag structures (intertemporal realism — "greed now, costly later")
Implement lagged consequences as **state accumulators**, not ad-hoc penalties. Four reusable types:
1. **Smoothed stress/debt stock:** `debt' = (1−λ_decay)·debt + λ_build·max(0, target−actual)`; `effect = β·debt`. For nutrient-shortfall debt, maintenance backlog, stockout risk, service deterioration, hedge misalignment.
2. **Distributed delay (K compartments)** → hump-shaped (peaks later, not next step): `z1' = z1 + (input − z1)/τ`; `z2' = z2 + (z1 − z2)/τ`; …; `delayed_effect = zK`; `τ = τ_total/K`. For delayed shell-quality / size-shift / deferred-maintenance-failure / procurement-into-book-cost / contract roll-through.
3. **Threshold with hysteresis** (absorb slack a while, then suddenly pay; recovery costs more than deterioration): `pressure = Σ aᵢ·stateᵢ`; regime flips on `θ_on`, off `θ_off`; `extra_cost = regime·severity(pressure)`. For packer-line failures past a backlog limit, overtime spirals, customer-service penalty mode.
4. **Adjustment-cost / inertia** (anti-exploit): `adj_cost = Σ κⱼ·|aⱼ,t − aⱼ,t−1|`. Makes rapid switching costly (transaction/reconfig/retraining/changeover/basis-loss/renegotiation); prevents oscillatory discrete-time-optimization artifacts.

Reusable `economic_state_templates`: procurement_basis_position, feed_nutrition_debt, shell_quality_delay, egg_size_mix_inertia, maintenance_backlog, labor_fatigue_backlog, customer_service_score, contract_rollover_position, capex_age_and_failure_risk.

## Calibration & validation
Target = **behavioral reconciliation**, not pretty equations. Sequence: (A) fix exogenous series + supplied primitives → (B) calibrate accounting identities/units → (C) back-solve static cost/revenue coefficients to one reconciled month → (D) calibrate lag params to multi-period behavior → (E) validate on a withheld month → (F) extreme-condition + structure tests before freeze. (UC Davis PMP logic: exact base-year reproduction + smooth responses away from it.) Static back-solve treats the reconciled month as identities (`other_variable_target = total − feed − labor − energy − pullet − depr − interest`). Lag fit = `argmin Σ wᵢ·RMSE(model, obs)` over profit/COP/cost-share/size-mix/quality + bias², subject to correct signs, monotonicity, bounded half-lives.

Three validation layers: (1) **structure tests** (Barlas: dimensions, stock conservation, sign constraints, edge cases — no feed→no feed cost; zero sales can't make positive AR; full hedge neutralizes covered-window spot sensitivity) — *do these first*; (2) **historical fit** (RMSE/MAPE/bias/Theil decomposition on monthly revenue/cost/COP/cumulative cash — diagnose bias vs level vs timing vs variance error); (3) **reproduction under perturbation** (perturb one lever, verify right direction + magnitude). Engineering tolerances: reconciled month rev/cost ≤1%, major cost-share ≤2pp; withheld MAPE ≤3–5%, ~zero bias, no sign failures; cycle cumulative-cash ≤3%, terminal balances reconcile exactly.

## Balance methodology (5 objectives) — production-grade; trimmed for us
1. **No dominant strategy:** scenario matrix over {flock age, feed cheap/normal/expensive, egg market weak/normal/strong, energy-cost season, contract tight/loose}; evaluate a policy library; `dominance_score(i,j) = mean_S 1{J(i,s) ≥ J(j,s)+ε}`; ε ≈ 1–2% cycle NPV; pᵢ dominant if it beats every other in ≥95% of states.
2. **Multiple near-optimal strategies:** `near_optimal(s) = {π : J(π,s) ≥ J*(s) − δ}`, δ = max(2%·|J*|, floor); cluster by action fingerprints (hedge-ratio path, days-of-cover, channel shares, capex timing, maintenance aggressiveness); want **≥3 qualitatively distinct clusters**.
3. **No reward-hacking exploit:** exploit hunt (grids, Latin-hypercube, hill-climb, CMA-ES, RL/ADP) with welfare constraints AND a shadow run without them — confirm a welfare-destructive policy does NOT beat the compliant optimum over the full cycle. Official leaderboard compares only compliant runs; shadow = exploit discovery. *(Potential-based reward shaping only IF dense reward exposed — N/A for us.)*
4. **State-dependent optimality:** `Q̂(x,a) = profit(x,a) + continuation(F(x,a,u))`; `switch_rate = mean over neighbor pairs 1{argmax_a Q̂(x) ≠ argmax_a Q̂(x')}`. Near-zero ⇒ fixed-dial optimum ⇒ retune (stronger lags, working-capital coupling, seasonal tariffs, carrying costs, contract frictions, customer heterogeneity).
5. **No single lever trivializes:** sensitivity ladder — tornado/OAT → Morris screening (efficient for many deterministic inputs) → Sobol total-order on the reduced set. Target: **largest total-order index < 35–40%, top-3 < 70%.**

## Reference policies (for scoring)
- **Optimum** = finite-horizon constrained optimal control: `max_{a} Σ βᵗ·profit + βᵀ·terminal s.t. x'=F, welfare/operational/financing constraints`. Bellman: `V_t(x) = max_a [profit + β·V_{t+1}(F(x,a,u))]`. Method by size: exact backward DP (small discrete; true optimum, state-explosion); approximate DP/fitted-VI (medium); receding-horizon MPC (large continuous; practical, not global); black-box policy search (few interpretable params; finds policy-class optimum); evolutionary/hybrid (mixed discrete/continuous; strong exploit finder, compute-heavy). Curse of dimensionality is real → if too many continuous states, solve within a **restricted-but-rich policy class** and document it.
- **Competent baseline** = transparent heuristic operator (NOT weak-random, NOT covert-optimizer): bounded-band rules (days-of-cover band; conservative hedge share; smooth channel shifts unless spread > threshold; on-schedule preventive maintenance unless liquidity binds; capex only if payback < threshold + covenant headroom; rolling-average triggers to avoid end-of-period gaming). Fit its rule params to "competent but not optimal" (simple monotone thresholds, bounded responsiveness, no omniscience). Survives bad conditions without obvious mistakes but leaves money on the table vs the dynamic optimum.
- **Scoring:** `raw = (J_agent − J_baseline)/max(J_opt − J_baseline, tiny)`; `reported = 100·raw`; **do NOT clip at zero** (active mismanagement scores below baseline). Average numerator/denominator over a fixed seeded scenario basket for robustness.

## Tuning loop + acceptance criteria
Loop: assemble sim w/ full audit logging → calibrate to one reconciled month + one cycle → build policy library → solve compliant optimum in chosen class → build competent baseline → exploit search → Morris then Sobol → retune lags/frictions/constraints → recompute → freeze only when criteria pass.
Acceptance: accounting realism (reconciled rev/cost ≤1%, no broken inventory/debt/AR-AP/capex identities); dynamic realism (cheap short-term actions improve near-term profit but create measurable later cost via explicit state; no instantaneous reversals of mix/quality/backlog/book-cost); no-dominant (≥3 near-optimal clusters within 1–3% of best NPV; no family beats all by >2% in >95% of states); no-exploit (best black-box/RL gain explainable by real business logic; no oscillatory/accounting-artifact policy beats optimum by >1% post-retune); state-dependence (best action changes across age/margin/season; fixed policy loses materially in some states); no-trivial-lever (largest total-order < 35–40%, top-3 < 70%); welfare integrity (no welfare-violating policy beats the compliant optimum over the cycle).

## Audit logging
Per step, log the profit decomposition: price / volume / mix / feed-procurement / feed-formulation / labor-productivity / energy-tariff / maintenance / financing-tax / risk-transfer / lagged-state penalties-recoveries. Makes calibration faster, exploit-hunting easier, leaderboard disputes resolvable, and distinguishes "economically smart" from "exploiting a state-transition/accounting bug."
