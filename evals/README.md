# evals/ — per-eval documentation

Eval: cross

One folder per evaluated species: `hen/` (the cage-free layer eval, the project's first and most
complete), `dairy/` (the PLF dairy eval, in design). Salmon and shrimp folders are created when the
first document for them lands — never before (ruling 13a).

**The rule (ruling 13b):** if a document belongs to one eval it lives under `evals/<eval>/`;
everything else — cross-eval methodology, shared evidence, repo process — stays in `docs/`.
Mixed documents live where their majority is; the minority side gets a pointer line, never a copy
and never a split.

Inner folders (same taxonomy in every eval; see each folder's README):
`design` · `research` · `nodes` · `world` · `judge` · `surface` · `runs` · `archive`.

File conventions: [docs/save-protocol.md](../docs/save-protocol.md).
