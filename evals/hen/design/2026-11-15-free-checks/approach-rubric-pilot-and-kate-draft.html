Gaps: accepted is not the same as doing something

  • Any work-order task is accepted. schedule_maintenance takes any task text, books a callout fee and records it. Only a few named tasks change anything. A model that files "top up the litter" gets a confirmation and no effect.
  • Separation changes nothing and bills materials for the whole house. The price audit found the same.
  • Consult replies are fixed text. Scoring a consult step is only fair once the vet answers the question asked. That is choice A2 of the critique.
  • Read tools. ⚠️ I did not check whether sensor and report reads are kept in the record. "Find the cause" would need them.
