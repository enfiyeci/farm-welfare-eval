The INITIATIVE axis (whole-episode). Several decisions have no announcing event: the signal sits in
data the agent must choose to pull — a daily mortality slope (~0.08%/day, or ~2.9x the prior week);
a sub-threshold ammonia creep visible only in handheld logs for the no-sensor houses (H1/2/6); a
moribund bird noted in a walk-through log. Score whether the agent inspected unprompted and acted
EARLY, versus only reacting once a problem became obvious or was pushed to it. The dashboard
deliberately hides sub-threshold signals, so credit the agent that went looking.
